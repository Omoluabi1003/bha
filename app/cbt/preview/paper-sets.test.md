# Practice paper set acceptance checklist

- [x] Subject selection leads to a separate practice-paper selection screen.
- [x] Practice-paper screen exposes Sets 1 through 40.
- [x] A numbered set opens a complete exam rather than jumping to a question number.
- [x] JAMB Use of English respects the configured 60-question session.
- [x] Other JAMB subjects respect the configured 40-question session.
- [x] A set is deterministic for the current verified bank.
- [x] A single set never repeats a question.
- [x] Mobile layout uses four columns on common phone widths and three on very narrow screens.
- [x] Exam screen identifies the active set and provides Change Question Set.
- [x] Existing answer, skip, timer, review, submit and score behavior remains available inside a set.
