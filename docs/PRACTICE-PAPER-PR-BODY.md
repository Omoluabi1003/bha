# Pull Request Notes

## What changed

The CBT flow now treats numbers 1–40 as complete practice-paper sets. A learner selects exam, subject, then a numbered set before answering the full configured multiple-choice paper.

## Important content note

The current verified banks are not yet large enough to provide 40 mutually exclusive papers for every subject. Sets are deterministic and never duplicate a question within one paper, but different sets can overlap while the original BHA question banks grow.
