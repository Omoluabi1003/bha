# Practice Sets Release Notes

## Changed

The numbered 1–40 grid is now a library of complete practice papers rather than an individual-question navigator.

A learner now chooses an examination, subject and numbered set before starting. The selected set carries the configured full question count and its own timer/progress/submission flow.

## Content status

The architecture exposes all 40 paper slots immediately. Sets are generated deterministically from each verified subject bank. Until banks reach the full non-overlap target, different sets can share source questions. A question is never duplicated within one paper.
