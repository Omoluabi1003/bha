# CBT Content Integrity

BHA practice papers should be exam-standard and syllabus-aligned while remaining original BHA educational content.

Rules:

- Use official examination syllabi and publicly documented examination structure as specifications.
- Do not bulk-copy commercial past-question books or unauthorized reproductions.
- Store a correct option and topic for every authored question.
- Review questions for ambiguity, duplicated stems and incorrect distractors before marking a bank verified.
- Do not repeat the same question inside a single practice paper.
