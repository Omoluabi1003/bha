# Practice Paper UX

The old Question Navigator grid represented question numbers and caused the numbered controls to be interpreted incorrectly.

The replacement flow intentionally separates the concepts:

1. Choose exam.
2. Choose subject.
3. Choose Set 1–40.
4. Enter that set's complete multiple-choice paper.
5. Navigate questions inside the paper with Previous / Next / Review Unanswered.
6. Submit the selected set and receive its score.

The set grid is responsive so the 40-paper library remains usable on phones without the mobile clipping seen in the earlier navigator layout.
