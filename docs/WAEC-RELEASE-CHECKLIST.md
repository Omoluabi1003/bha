# WAEC CBT release checklist

Before a WAEC picker release:

1. Catalog matches the current WAEC Nigeria 2026/2027 entry-regulation subject list.
2. Oral, practical and performance papers remain components of parent subjects rather than duplicate cards.
3. Every visible subject reaches its configured question count after `verifiedPool()` filtering.
4. No cross-subject question-ID collisions exist.
5. Structural readiness is never described as academic certification.
6. Literature-in-English, Hausa, Igbo, Yoruba and Arabic prescribed-text/version review is handled separately against WAEC's 2026-2030 notices.
7. Theory/practical/performance preparation should eventually be represented inside the relevant subject experience rather than by fake standalone subjects.
