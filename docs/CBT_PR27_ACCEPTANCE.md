# Acceptance Checklist

- Outer selector represents complete question sets.
- Inner navigator represents questions within the selected set.
- Set size follows 40/50/60 session configuration.
- Synthetic set-padding markers fail the bank quality gate.
- Question IDs within a set must be unique.
- Database model can persist published set membership.
- Attempts can reference the exact selected question set.
- Legacy incomplete or padded subjects remain Bank in Review.
