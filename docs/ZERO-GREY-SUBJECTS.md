# Zero-grey CBT subjects

This follow-up starts from the main branch after PR #29.

The CBT catalog now has starter question coverage for the subjects that previously displayed `BANK IN REVIEW · 0/40 VERIFIED`, including Hausa, Igbo, Yoruba, French, Arabic, Art/Visual Art, Music, Home Economics/Home Management, Catering Craft, Foods & Nutrition, Physical/Health Education, Technical Drawing, Nigerian History and the new WAEC vocational subjects.

`auditCBTCatalog()` provides a programmatic guard for any catalog subject whose available bank falls below its configured session size.

These are original BHA starter questions. They are not scraped or copied commercial past-paper content. Editorial expansion should continue toward fully independent 40-set banks.
