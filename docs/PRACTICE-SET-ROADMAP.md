# Practice Set Roadmap

1. Ship the Set 1–40 paper architecture.
2. Expand high-demand JAMB subject banks first: Use of English, Mathematics, Biology, Chemistry, Physics, Government and Economics.
3. Tag authored questions by syllabus topic and difficulty.
4. Grow each non-English JAMB bank toward 1,600 verified questions and English toward 2,400.
5. Persist explicit authored set membership once the bank is large enough to guarantee 40 fully independent papers.
6. Extend subject-specific WAEC and NECO paper configurations rather than assuming one universal SSCE pattern.
