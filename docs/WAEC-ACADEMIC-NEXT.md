# WAEC academic follow-up

Structural readiness is only the first gate. The next phase should audit individual questions against current WAEC syllabuses and Chief Examiners' guidance where available, recompute quantitative answers, review native-language authenticity, and verify 2026-2030 prescribed texts for Literature-in-English and relevant languages.

No question should be described as academically WAEC-certified merely because it passes the software validator or makes a subject card active.
