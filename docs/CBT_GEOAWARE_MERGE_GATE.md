# GeoAware CBT Merge Gate

Before a numbered CBT set is marked available:

- The outer number opens a complete question set, not a single question.
- JAMB Use of English contains 60 distinct questions per set.
- JAMB non-English subjects contain 40 distinct questions per set.
- WAEC, NECO and BHA practice sets use the configured 50 distinct questions per set until a subject-specific verified format supersedes the practice policy.
- No duplicated question IDs.
- No duplicated normalized stems.
- No `Set N` relabelling used to disguise repeated content.
- The inner question navigator covers every question in the selected set.
- Skip, review, autosave, timer and submission operate within the selected set.
- Incomplete numbered sets remain locked as Bank in Review.
