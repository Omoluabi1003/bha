# Question Bank Growth

The practice-paper UI supports 40 complete sets now. BHA should expand each verified subject bank using original questions aligned to official Nigerian examination syllabi and learning objectives.

Targets for fully non-overlapping sets:

- JAMB Use of English: 2,400 verified questions (40 × 60).
- Other JAMB subjects: 1,600 verified questions each (40 × 40).
- WAEC/NECO subjects: derive the target from the configured paper size for that subject.

Until those targets are reached, numbered sets are stable and contain no duplicates within a paper, but different sets can share questions. This is preferable to fabricating or duplicating a question inside one test.
