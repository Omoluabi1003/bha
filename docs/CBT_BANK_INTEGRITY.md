# BHA CBT Bank Integrity Standard

BHA follows the GeoAware-Core principle that visible completeness must represent real completeness.

## Numbered selector meaning

The numbered selector is the navigation for one examination question set.

- Selector 1 opens Question 1.
- Selector 2 opens Question 2.
- Each following selector opens its corresponding distinct question.
- A 40-question session therefore has selectors 1 through 40 and 40 distinct questions.
- A 50-question session has selectors 1 through 50 and 50 distinct questions.
- A 60-question session has selectors 1 through 60 and 60 distinct questions.

A selector does not represent a separate 40/50/60-question bank. The full numbered selector collectively represents the active question set.

## Professional gate

A subject is not advertised as ready merely because code can generate the requested array length. Repeated stems, relabelled `Set N` questions, and duplicated IDs are rejected by the bank integrity gate. Such subjects remain unavailable as `Bank in Review` until a genuinely distinct bank is supplied.

## Session construction

The exam/session layer chooses the required number of distinct questions from an approved subject bank. Question order may be randomized for a new attempt, but the selected question IDs and order must remain stable for that attempt so refresh, autosave, skip/review, timing and final submission all refer to the same question set.
