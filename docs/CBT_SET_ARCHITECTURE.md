# Numbered CBT Set Architecture

The outer numbered selector is a set selector, not a question navigator.

Selecting Set 1 starts a complete subject question set. Selecting Set 2 starts a different complete subject question set. Each set contains the configured 40, 50 or 60 distinct questions.

The inner examination runner then provides Question 1 through Question 40/50/60 navigation, including skip, review, autosave, timer and submission.

No question record may be recycled across numbered sets when the product represents those sets as distinct. If the approved bank is not large enough to supply all configured sets, the unavailable sets remain locked rather than being padded with repeated questions.
