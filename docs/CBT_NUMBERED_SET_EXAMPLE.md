# Example

For a JAMB Mathematics bank:

- Set 1 contains 40 distinct Mathematics questions.
- Set 2 contains another 40 distinct Mathematics questions.
- Set 3 contains another 40 distinct Mathematics questions.

For JAMB Use of English, each set contains 60 distinct questions.

For a BHA 50-question practice format, each numbered set contains 50 distinct questions.

The outer numbered selector chooses the set. After a set is opened, the inner question navigator moves through the 40, 50 or 60 questions belonging to that set.
